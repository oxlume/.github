# Contributing to Oxlume

Thank you for your interest. The Oxlume product itself is not open source; this organization holds our public documents, brand files and the website.

## Where to write

| Repository | Use it for | How to reach us |
|---|---|---|
| [responsible-ai](https://github.com/oxlume/responsible-ai) | Questions and suggestions about how the AI is designed | Open an issue |
| [oxlume-website](https://github.com/oxlume/oxlume-website) | Typos, broken links, translation errors (EN, UA, DE, ES) | Open an issue or a small pull request |
| [brand-assets](https://github.com/oxlume/brand-assets) | Logo and brand use requests | Email info@oxlume.com |
| [.github](https://github.com/oxlume/.github) | Organization profile and these policies | Email info@oxlume.com |

To join the beta, use the form on [oxlume.com](https://oxlume.com/contact.html).

## Issues

- Search existing issues first.
- One topic per issue, with a clear title.
- For website issues, add the page, the language and a screenshot if you can.
- Never include real personal data, customer photos or access tokens.

## Pull requests

Small pull requests are welcome: a fixed typo, a better translation, a broken link. For anything bigger, open an issue first so we can agree on the approach.
